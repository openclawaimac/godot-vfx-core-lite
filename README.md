# VFX Core 2D Lite for Godot 4

*by huginhelm*. Free, MIT-licensed sampler of **VFX Core 2D for Godot 4** (version 1.0.0).

Procedural 2D effects for Godot 4.4+. One call plays an effect; every effect is pooled,
takes any colour and any scale, and has a smooth or a pixel style. Effects use only
`CPUParticles2D` and our own canvas shaders, so they look the same on Compatibility,
Mobile and Forward+, and on the web export.

```gdscript
VfxCore.play(&"explosion_small", global_position)
VfxCore.play(&"explosion_small", global_position, {"color": Color.ORANGE, "scale": 1.5})
VfxCore.play(&"hit_spark", hit_pos, {"normal": hit_normal})
VfxCore.apply(&"hit_flash", $Sprite2D)
VfxCore.shake(0.4)
```

## What is in Lite

The full runtime (`VfxCore`, `VCEffect2D`, `VCPool`, `VCPreset`, handles, pooling,
budgets, pixel mode, camera shake and hit-stop), the Destruction Core hook
(`VCHookDestruction`), the demo browser, and these effects:

- `explosion_small`
- `debris_stone`
- `dust_puff`
- `shock_ring`
- `smoke_puff`
- `muzzle_rifle`
- `hit_spark`
- `coin_burst`
- `hit_flash`

The effect list with presets is in `docs/EFFECTS.md`; the API is in `docs/API.md`.

## Install

1. Copy `addons/vfx_core` into your project.
2. Enable *VFX Core 2D Lite for Godot 4* in *Project Settings → Plugins* (or add the
   autoload `VfxCore` → `res://addons/vfx_core/runtime/vfx_core.gd`).
3. `VfxCore.play(&"explosion_small", get_global_mouse_position())`.

Open `demo/demo.tscn` to browse the effects and copy their ids. See `QUICKSTART.md`.
